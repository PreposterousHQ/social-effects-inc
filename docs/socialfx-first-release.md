# Social FX first live release

Published route: `/socialF(X)/`. Version 0.1 is a browser-persisted workspace and production simulation. It is intentionally labeled throughout so fictional data cannot be mistaken for actual organizations, commitments, AI actions or impact.

The public app is built in TypeScript and React. Source is under `socialfx-src`; generated deploy files are under `socialF(X)`. It adds a route to the existing GitHub Pages site and does not change hosting, domain configuration, company pages or Ledger content.

Use Simulation to rehearse Unbreakable Spirit, shape the seven-lens Canvas, change the collection deadline, test availability, confirm logistics, cover fuel, partially allocate couches, record receipt and inspect evidence. Use My network for conversation-led notes and contribution availability. Both save only to the current browser. Export backups to keep another copy.

Shared database persistence, accounts, live AI/voice, sending, payments and signatures remain unconnected. This distinction is displayed in the app and is part of the release handoff. Future implementation should keep canonical IDs and the original platform specification's relational model, while preserving the latest gift-based pilot and conversation-led onboarding decisions.

## Pre-production update — 31 October 2026

The simulation now opens on a numbered Start here path. The prepared Unbreakable Spirit brief uses a $300M scenario: $100M essential filmmaking and $200M production spending shaped by the script and community benefit. Land and a tiny-home community are required; a willing host is necessary. All film profits support the built community; no separate paid marketing budget is assumed. Gifted labor frees budget rather than automatically increasing the cash total.

Expandable briefs cover land, homes, whole sets, a barn, surplus food/goods, and gifted time. They are discussion material, not interactive asset-management workflows. The couch exercise remains the interactive demonstration. AI and voice remain simulated/not connected. Browser-only storage remains unchanged.

Existing snapshots receive refreshed untouched seed notes and an initial Liaison stage; edited notes and exercise history remain intact. Scenario versioning makes this upgrade idempotent. Twelve domain tests, TypeScript, build, sharing freshness and existing routing/navigation checks pass.

## Mixed set release — 30 October 2026 (New York)

The interactive rehearsal now covers 10 couches, 5 boxes of clothes, 3 cars, one assorted-equipment lot and one miscellaneous lot from the Unbreakable Spirit set. The two lots have unspecified contents rather than invented item counts. Each group has independent dates, interest, logistics, allocation and receipt records, plus a prominent reset button. Resetting a group restores its example logistics and leaves other groups and organizational records intact. The existing full-demo reset remains available separately.

Vehicle parking/transport is matched separately from furniture and other items. Transport cost is discussed in the role-play and sponsor-covered; the earlier fixed $60 couch assumption is removed. Reports include every item group. Older active three-couch runs are archived in JSON backups as the expanded exercise opens; edited notes and organization records are preserved.

Validation: 16 tests cover quantities, partial allocations, per-group completion/reset/replay, serialized state, matching, stale writes and migration archives. Typecheck, build and existing sharing/routing/navigation checks pass.
