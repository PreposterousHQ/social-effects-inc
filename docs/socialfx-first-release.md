# Social FX first live release

Published route: `/socialF(X)/`. Version 0.1 is a browser-persisted workspace and production simulation. It is intentionally labeled throughout so fictional data cannot be mistaken for actual organizations, commitments, AI actions or impact.

The public app is built in TypeScript and React. Source is under `socialfx-src`; generated deploy files are under `socialF(X)`. It adds a route to the existing GitHub Pages site and does not change hosting, domain configuration, company pages or Ledger content.

Use Simulation to rehearse Unbreakable Spirit, shape the seven-lens Canvas, change the collection deadline, test availability, confirm logistics, cover fuel, partially allocate couches, record receipt and inspect evidence. Use My network for conversation-led notes and contribution availability. Both save only to the current browser. Export backups to keep another copy.

Shared database persistence, accounts, live AI/voice, sending, payments and signatures remain unconnected. This distinction is displayed in the app and is part of the release handoff. Future implementation should keep canonical IDs and the original platform specification's relational model, while preserving the latest gift-based pilot and conversation-led onboarding decisions.
